# 🤖 AI-Powered WhatsApp Assistant

An intelligent WhatsApp chatbot built using n8n and LLMs to automate real-time conversations with support for text, audio, and image inputs.

---

## 🚀 Features

- 💬 Automated WhatsApp responses using AI
- 🧠 LLM-based contextual reply generation
- 🎤 Speech-to-text processing for audio messages
- 🖼️ Image input handling using AI APIs
- 🔄 End-to-end workflow automation using n8n
- 🔗 API integrations with JSON data handling

---

## 🛠️ Tech Stack

- n8n (Workflow Automation)
- OpenAI API (LLM)
- WhatsApp API (Twilio / Meta)
- JSON, REST APIs

---

## ⚙️ How It Works

1. User sends message on WhatsApp
2. n8n workflow triggers
3. Input is processed (text/audio/image)
4. LLM generates response
5. Reply sent back automatically
